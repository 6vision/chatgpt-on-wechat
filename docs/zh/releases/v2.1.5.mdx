## 🗂 工作空间与文件预览

对话页面新增工作空间的可视化管理，Agent 生成的文稿、网页、图片等可直接预览，Web 控制台与桌面客户端均已支持。

- **工作空间浏览**：在面板内浏览工作空间目录下的文件，支持搜索与下载到本地。
- **文件预览**：HTML 页面、文档、图片等可在侧边面板中直接打开，回复中的文件路径渲染为可点击的卡片。
- **文件引用**：支持将工作空间文件拖入对话，或在输入框中用 `@` 引用文件与目录，直接加入上下文。

## 🔧 基础工具优化

对文件搜索、读取、写入、编辑、命令行等工具进行了系统性优化，提升 Agent 的文件操作与代码编写等核心能力。

- **新增文件搜索工具**：`search_files` 支持按内容或文件名检索工作空间，内置 ripgrep 作为默认后端，大目录下检索速度显著提升。Thanks @Maaayhan (#2982)
- **读取输出带行号**：`read` 的输出统一携带行号，便于精确定位与引用指定行。
- **编辑准确性提升**：`edit` 工具修复模糊匹配时改动原有缩进、以及内容重复时定位错误的问题；新增全部替换能力；文件被外部修改后给出提示。
- **写入语法校验**：`write` / `edit` 工具对结构化文件增加写入前格式校验；对代码文件增加语法解析，将语法错误提示给 Agent。
- **命令支持后台运行**：`bash` 工具支持后台运行命令，可用于启动服务、跟踪日志等长耗时任务；提升前台命令的默认超时时间。
- **中止即时生效**：点击中止或执行 `/cancel` 时，正在运行的命令即时终止。

相关文档：[文件搜索](https://docs.cowagent.ai/zh/tools/search-files)

## 🧠 上下文管理

- **上下文压缩**：新增 `/compact` 命令，可手动触发对话上下文的智能总结压缩，可有效降低 Token 消耗。
- **命令统一**：`/clear` 统一为清空当前会话上下文，`/context clear` 作为别名继续兼容。
- **默认容量提升**：调高默认上下文上限，长对话触发裁剪的时机更晚。

相关文档：[上下文管理](https://docs.cowagent.ai/zh/memory/context)

## 🖥 桌面客户端

- **Mac 原生运行**：修复 macOS arm64 安装包中存在 x64 后端的问题，大幅提升 Apple Silicon 机型上的主程序运行及浏览器工具使用速度。
- **飞书通道增加**：修复客户端中飞书通道缺失的问题。飞书 SDK 改为在首次启用通道时按需下载精简依赖（约 1MB）。Thanks @EvanProgramming (#2988)
- **更新提示优化**：同一版本的更新弹窗仅自动弹出一次。
- **内置文件搜索后端**：Windows 客户端随包内置 ripgrep，文件搜索开箱即用。

下载地址：[CowAgent客户端](https://cowagent.ai/zh/download/)

相关文档：[桌面客户端](https://docs.cowagent.ai/zh/guide/desktop)

## ✨ 提示词一键优化

Web 端输入框新增提示词优化功能，可将用户输入文本补全为更完整清晰的指令，优化规则支持自定义模板。Thanks @sufan721 (#2989)

## 🔒 安全加固

- **MCP 与文件写入加固**：修复一条可被提示词注入利用的攻击链——恶意内容诱导 Agent 改写 MCP 配置，进而执行任意命令、窃取密钥。Thanks @Correctover (#2968)
- **凭据文件保护**：修复 `edit` 工具可绕过凭据保护、读写 `~/.cow/.env` 的问题。

## 🛠 体验优化与修复

- **bash 配置生效**：修复 `config.json` 中 `tools.bash.timeout` 与 `tools.bash.safety_mode` 被忽略的问题。Thanks @EvanProgramming (#2986)
- **记忆工作空间路径**：修复全局记忆配置中工作空间路径解析不正确的问题。Thanks @Maaayhan (#2992)
- **对话历史保护**：修复记忆索引自我修复时，可能连带清空对话历史的问题。
- **会话删除**：修复删除会话后，仍在执行的回复会将该会话重新写回列表的问题。
- **浏览器启动**：修复浏览器已在运行时重复启动实例的问题
- **工具返回准确性**：修复部分工具的错误返回，包括对 `grep` / `find` 的退出码判定错误、浏览器脚本执行误报语法错误、图片相对路径解析失败等，减少无效重试。

## 📦 升级方式

- **源码部署**：执行 `cow update` 一键升级，或手动拉取代码后重启。详见 [更新升级文档](https://docs.cowagent.ai/zh/guide/upgrade)。
- **桌面客户端**：可在客户端内自动检查并一键更新，或前往 [下载页](https://cowagent.ai/zh/download/) 获取最新版本。
