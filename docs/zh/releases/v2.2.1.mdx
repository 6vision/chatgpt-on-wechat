## 📁 产物中心

新增「产物」页面，集中管理对话中生成的文件，Web 控制台与桌面客户端均已支持：

- **自动收录**：Agent 生成的文档、网页、图片、视频都会自动在产物中心展示，跨 Agent 按时间线排列。
- **预览与回溯**：支持按类型、Agent 筛选和搜索，可直接预览，并跳转回生成该文件的对话（Thanks @rudycelekli #3732）。
- **置顶与管理**：支持置顶、重命名、移除；对话中的文件卡片可直接定位到产物中心。产物页面默认隐藏，可在菜单编辑中开启。

- **Mermaid 图表**：Mermaid 代码块可切换为图表预览，支持缩放与全屏。Thanks @akushonkamen (#3620)
- **长会话加载优化**：提升工具调用较多的长会话的打开速度。
- **问题修复**：新会话标题不再丢失，默认 Agent 的会话管理操作不再报错（Thanks @6vision #3625, #3617）；配置项一并生效，工作空间文件按所属 Agent 保存（Thanks @aniruddhaadak80 #3454, #3488）。

## 🔌 开放 Agent 对话 API

支持开放标准对话接口，可接入第三方客户端，或在业务系统中直接调用 Agent：

- **开关与密钥**：在「配置」页一键开启并生成 API Key，关闭后 Key 保留；也支持通过配置文件或环境变量开启（Thanks @AaronZ345 #3068、@Bdysj #3342）。
- **指定 Agent 与模型**：通过 `agent_id` 指定 Agent，通过 `model` 指定模型，未指定时使用 Agent 的默认模型。
- **多轮会话**：默认由调用方传入完整消息历史；传入 `conversation_id` 后由服务端保存历史，只需发送最新消息。
- **完整输出**：支持流式与非流式响应，返回思考内容、Token 用量及工具调用过程（Thanks @AaronZ345 #3068、@c020627 #3545, #3588）。

相关文档：[对话 API](https://docs.cowagent.ai/zh/extensions/chat-api)

## 📐 模型缓存与上下文成本优化

- **Claude 提示词缓存**：缓存系统提示词、工具定义与对话前缀，显著提升缓存命中率，降低 Token 成本与响应延迟；缓存时长可通过 `claude_cache_ttl` 配置。
- **裁剪预留空间**：上下文裁剪后预留空间，后续若干轮不再改动前缀，长会话也能持续命中缓存。
- **预算即时生效**：修改上下文预算与最大步数后直接作用于运行中的 Agent，不再清空会话。
- **压缩保留工具记录**：压缩后的历史轮次保留工具调用摘要，避免模型编造执行结果（Thanks @tsumon #3634）。
- **问题修复**：压缩期间到达的消息不再丢失，孤立工具结果的清理更准确（Thanks @c020627 #3518、@rudycelekli #3652, #3653）。
