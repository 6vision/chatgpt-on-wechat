---
title: 自定义菜单
description: 调整侧边栏菜单的顺序和分组，把常用的产物和网页放进菜单
---

侧边栏菜单可以按自己的习惯调整：重新排序和分组、隐藏不常用的页面，还可以把 Agent 生成的网页、文档或任意网址放进菜单，像内置页面一样一键打开。Web 控制台和桌面客户端共用同一份菜单。

## 打开菜单编辑器

有三个入口：

- 鼠标悬停在侧边栏的分组标题上，点击右侧出现的编辑图标
- 点击侧边栏左下角的版本号（Web 控制台）或「更多」按钮（桌面客户端），选择「自定义菜单」
- 在「产物」页预览网页或 Markdown 文档时，点击「添加到菜单」

{/* TODO: 截图 - 菜单编辑器 */}

在编辑器中修改后点击保存即可生效。

## 排序与分组

- 按住每一项左侧的拖动手柄，可以调整顺序，也可以拖到其他分组
- 点击「添加分组」新建分组，分组名称可直接修改
- 删除分组前，需要先把其中的内置页面移到其他分组

## 内置页面

对话、智能体、配置、能力等内置页面可以：

- **改名和换图标**：名称留空时使用默认名称
- **隐藏**：点击眼睛图标隐藏或重新显示。「对话」和「配置」不能隐藏，保证随时能回到设置
- **重新加回**：移除的内置页面可以在「添加 → 内置页面」中找回

「产物」页面默认隐藏，需要时在编辑器中显示即可。

## 添加产物

通过「添加 → 产物（HTML / Markdown）」搜索 Agent 生成的网页或 Markdown 文档并放进菜单。点击菜单项会在控制台内直接打开，文件更新后看到的也是最新内容，适合放置 Agent 维护的报表、看板和知识文档。

文件被删除后，菜单项会提示文件已不存在，可在编辑器中移除。

## 添加网页链接

通过「添加 → 网页链接」填写名称和以 `http://` 或 `https://` 开头的地址，并选择打开方式：

- **内嵌**：在控制台内打开，适合内部系统、数据看板等
- **新标签**：在新的浏览器标签页中打开

<Tip>
  部分网站禁止被其他页面内嵌，内嵌打开时会显示空白，改为「新标签」即可。内嵌页面的右上角也提供「新标签打开」按钮。
</Tip>

## 恢复默认

在编辑器中点击「恢复默认」，菜单会恢复为内置的默认菜单，添加的产物和链接会被移除。

## 菜单文件

菜单保存在默认智能体工作空间的 `system/menu.json` 中（源码部署默认为 `~/cow/system/menu.json`），由 Web 控制台和桌面客户端共同读取。某一端没有的页面会在该端跳过，同时保留在菜单中供另一端使用。

文件也可以手动编辑，格式如下；无法解析时会忽略该文件并使用默认菜单。

```json
{
  "version": 1,
  "groups": [
    {
      "id": "chat",
      "title": "",
      "items": [
        { "id": "chat", "type": "builtin", "view": "chat", "title": "", "icon": "", "hidden": false },
        { "id": "m_report", "type": "artifact", "title": "周报", "icon": "chart", "path": "/Users/me/cow/websites/report.html" },
        { "id": "m_board", "type": "url", "title": "看板", "icon": "gauge", "url": "https://example.com/board", "open": "embed" }
      ]
    }
  ]
}
```

| 类型 | 说明 | 字段 |
| --- | --- | --- |
| `builtin` | 内置页面 | `view` 页面名称，`hidden` 是否隐藏 |
| `artifact` | 产物 | `path` 文件的绝对路径，仅支持 HTML 和 Markdown |
| `url` | 网页链接 | `url` 网页地址，`open` 为 `embed`（内嵌）或 `tab`（新标签） |
