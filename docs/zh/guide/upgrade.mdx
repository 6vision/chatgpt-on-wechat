## 命令升级（推荐）

使用 `cow update` 一键完成代码更新和服务重启：

```bash
cow update
```

该命令会自动完成以下流程：

1. 拉取最新代码（`git pull`）
2. 停止当前服务
3. 更新 Python 依赖
4. 重新安装 CLI
5. 启动服务

<Note>
  如果未安装 Cow CLI，也可以使用 `./run.sh update` 完成相同操作。
</Note>


## 控制台一键更新

源码安装也可以直接在 Web 控制台升级，不必再开终端。

1. 点击左侧栏底部的版本号，弹出上拉菜单。打开菜单时**不会**访问 GitHub。
2. 点击 **检查更新**，才会拉取版本信息。这是唯一的网络请求；若有新版本，同一项会变成 **立即更新** 并带一个红点提示。
3. 点击 **立即更新**。控制台复用 `cow update` 的同一条路径（`git pull`、安装依赖、重装 CLI），然后重启服务。菜单里的 **版本说明** 则会打开 GitHub releases 页面查看完整变更。

更新只操作 git 代码目录：用户数据在仓库之外（`agent_workspace`，默认 `~/cow`），`config.json` 也被 gitignore，所以 `git pull` 不会覆盖它们，无需备份。更新前会记录当前 git 提交，如果新代码无法 import，会重置回该提交，且不杀死正在运行的进程。

更新成功后，控制台会自动重连并显示新版本号。

<Note>
  Docker 镜像和桌面客户端不能用这个按钮。Docker 仍使用 `docker compose pull`；桌面客户端继续走内置更新。Windows 上请在终端执行 `cow update`，Web 控制台无法从进程内部完成重启。
</Note>

### 回滚

如果更新成功但新版本工作异常，回退到上一个提交即可：

```bash
cow stop
git reset --hard <previous-commit>   # tmp/web-update-status.json 中会记录
cow start
```

## 手动升级

在项目根目录下执行：

```bash
git pull
pip3 install -r requirements.txt
pip3 install -e .
```

更新完成后重启服务：

```bash
# 使用 Cow CLI (推荐)
cow restart

# 或使用 run.sh
./run.sh restart

# 或使用 nohup 直接运行
kill $(ps -ef | grep app.py | grep -v grep | awk '{print $2}')
nohup python3 app.py & tail -f nohup.out
```

## Docker 升级

<Tip>
  升级前先备份 `config.json`。
</Tip>

在包含 `docker-compose.yml` 的目录中执行下面每一步。Compose 从该目录挂载 `./cow-data`。在 `pull` 和 `up -d` 之前先把文件拷出来。重建后的容器拿不回这些文件。`docker cp` 对已停止的容器同样有效，所以在旧容器还在时拷贝。拷贝完成前不要执行 `docker compose down` 或 `docker rm`。已经设置 `COW_DATA_DIR` 时跳过拷贝：此时 `/app/config.json` 是镜像模板（`docker/Dockerfile.latest` 执行了 `cp config-template.json config.json`），拷贝会覆盖 `./cow-data/config.json`。没有 `COW_DATA_DIR` 时，保存的配置是可写层上的 `/app/config.json`，微信登录是 `/home/agent/.weixin_cow_credentials.json`。

### 1. 拷出文件

容器名不是 `chatgpt-on-wechat` 就换成你的名字。容器已经不在，文件也就没了。下面的命令如果打印出带路径的 `COW_DATA_DIR=`，跳过拷贝。空值不会有输出。没有输出时才拷贝。从未登录微信就删掉最后一行。

```bash
sudo docker inspect --format '{{range .Config.Env}}{{println .}}{{end}}' chatgpt-on-wechat | grep -E '^COW_DATA_DIR=.+'
```

```bash
mkdir -p ./cow-data
sudo docker cp chatgpt-on-wechat:/app/config.json ./cow-data/config.json
sudo docker cp chatgpt-on-wechat:/home/agent/.weixin_cow_credentials.json ./cow-data/weixin_credentials.json
```

### 2. 在 `up -d` 之前加入 `COW_DATA_DIR` 和 `./cow-data` 数据卷

把下面两项加进 compose 文件，或 NAS 的数据卷和环境变量设置。`docker compose pull` 不会修改已经保存的 compose 文件。每次启动时，compose 里已设置的环境变量会覆盖从 `config.json` 读入的同名配置。`CHANNEL_TYPE: 'web, weixin'` 以及 `DEEPSEEK_API_KEY: ''` 这种空字符串会替换文件中的值。要保留已保存的设置，就删掉或改掉这些变量。

```yaml
    environment:
      COW_DATA_DIR: '/home/agent/.cow'
    volumes:
      - ./cow:/home/agent/cow
      - ./cow-data:/home/agent/.cow
```

### 3. 拉取镜像，把文件交给 `agent`，再启动

`sudo docker cp` 会保留模式 `0600`，并把属主设为 root。`docker/entrypoint.sh` 只 `chown` 挂载目录，然后以 `agent` 运行，因此读不了这个微信文件。`docker/Dockerfile.latest` 用 `useradd -r` 创建 `agent`，没有固定 uid。先读出 uid 和 gid，把两个数字填进 `UID:GID`，没拷贝的路径删掉。镜像名不同就换掉。先 `chown`，再执行 `up -d`。

```bash
sudo docker compose pull
sudo docker run --rm --entrypoint id zhayujie/chatgpt-on-wechat -u agent
sudo docker run --rm --entrypoint id zhayujie/chatgpt-on-wechat -g agent
```

```bash
sudo chown UID:GID ./cow-data/config.json ./cow-data/weixin_credentials.json
```

```bash
sudo docker compose up -d
```

## 客户端升级

[桌面客户端](/zh/guide/desktop)内置自动更新能力，有新版本时会自动检查并提示，一键即可下载并重启完成升级。

你也可以随时前往[下载页](https://cowagent.ai/zh/download/)手动下载最新版本安装。
