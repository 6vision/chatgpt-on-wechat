列出**单个目录**下的内容，按字母排序，目录名带 `/` 后缀，包含隐藏文件。

## 依赖

无额外依赖，默认可用。

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `path` | string | 否 | 目录路径，默认工作空间根目录，相对路径基于工作空间目录 |
| `limit` | integer | 否 | 最大返回条目数，默认 500 |

## 输出示例

```
__init__.py
__pycache__/
credentials.py
diff.py
file_state.py
```

超过 500 条或 50KB 时会截断。

<Note>
  `ls` 只看一层，用于「这个目录里有什么」。要跨目录递归找某个文件，请用 [`search_files`](/zh/tools/search-files) 的 `target=files`。
</Note>

## 使用场景

- 浏览项目结构
- 确认目录是否存在、里面有哪些文件
- 写入文件前查看同级已有内容
