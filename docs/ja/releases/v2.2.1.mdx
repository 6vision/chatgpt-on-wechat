## 📁 成果物センター

会話の中で作成されたファイルをまとめて管理できる「成果物」ページを追加しました。Web コンソールとデスクトップクライアントの両方に対応しています：

- **自動収録**：Agent が作成したドキュメント、Web ページ、画像、動画は自動で成果物センターに表示され、複数の Agent の成果物がタイムラインに並びます。
- **プレビューと遡及**：種類や Agent での絞り込みと検索に対応し、その場でプレビューできるほか、ファイルを作成した会話へ戻れます（Thanks @rudycelekli #3732）。
- **ピン留めと管理**：ピン留め、名前の変更、削除ができます。会話内のファイルカードから成果物センターの該当ファイルへ直接移動できます。成果物ページは初期状態では非表示で、メニューエディタから表示できます。

## 🧭 カスタムメニューとコンソールの改善

- **カスタムメニュー**：Web コンソールとデスクトップクライアントで、メニューのグループ、順序、名前、アイコン、表示状態をカスタマイズでき、設定は両方で共有されます。成果物ファイルや Web リンクもメニュー項目として追加できます。詳しくは [カスタムメニュー](https://docs.cowagent.ai/ja/extensions/custom-menu) を参照してください。

- **Mermaid 図**：Mermaid コードブロックを図のプレビューに切り替えられ、拡大縮小と全画面表示に対応します。Thanks @akushonkamen (#3620)

## 🔌 Agent チャット API の公開

標準的なチャット API を公開しました。サードパーティのクライアントから接続したり、業務システムから Agent を直接呼び出したりできます：

- **スイッチとキー**：「設定」ページでワンクリックで有効にして API キーを生成でき、無効にしてもキーは保持されます。設定ファイルや環境変数で有効にすることもできます（Thanks @AaronZ345 #3068、@Bdysj #3342）。
- **Agent とモデルの指定**：`agent_id` で Agent を、`model` でモデルを指定します。モデルを指定しない場合は Agent のデフォルトモデルを使用します。
- **マルチターン会話**：デフォルトでは呼び出し側が完全なメッセージ履歴を送信します。`conversation_id` を渡すとサーバー側で履歴を保存し、最新のメッセージだけを送ればよくなります。
- **完全な出力**：ストリーミングと非ストリーミングの両方に対応し、思考内容、トークン使用量、ツール呼び出しの過程を返します（Thanks @AaronZ345 #3068、@c020627 #3545, #3588）。

## 📐 モデルキャッシュとコンテキストコストの最適化

- **Claude プロンプトキャッシュ**：システムプロンプト、ツール定義、会話のプレフィックスをキャッシュし、キャッシュヒット率を大幅に高めてトークンコストと応答遅延を削減しました。キャッシュの保持時間は `claude_cache_ttl` で設定できます。
- **トリミング後の余白確保**：コンテキストのトリミング後に余白を確保し、その後の数ターンはプレフィックスを変更しないため、長いセッションでもキャッシュにヒットし続けます。
- **予算変更の即時反映**：コンテキスト予算と最大ステップ数の変更が実行中の Agent にすぐ反映され、セッションがクリアされなくなりました。
- **圧縮時にツール記録を保持**：圧縮された履歴ターンにツール呼び出しの要約を残し、モデルが実行結果を捏造するのを防ぎます（Thanks @tsumon #3634）。
- **不具合修正**：圧縮中に届いたメッセージが失われなくなり、孤立したツール結果のクリーンアップがより正確になりました（Thanks @c020627 #3518、@rudycelekli #3652, #3653）。

## 📦 アップグレード方法

- **ソースデプロイ**：`cow update` でワンクリック更新するか、Web コンソールのサイドバーのバージョンメニューから更新するか、最新コードを取得して再起動します。詳しくは[アップグレードガイド](https://docs.cowagent.ai/ja/guide/upgrade)を参照してください。
- **デスクトップクライアント**：クライアント内で更新を確認してワンクリックで更新するか、[ダウンロードページ](https://cowagent.ai/download/)から最新版を入手できます。
