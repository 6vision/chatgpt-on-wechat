サイドバーメニューは使い方に合わせて調整できます。並べ替えやグループ分け、あまり使わないページの非表示に加えて、Agent が作成した Web ページやドキュメント、任意の URL をメニューに追加し、組み込みページと同じようにワンクリックで開けます。Web コンソールとデスクトップクライアントは同じメニューを共有します。

## メニューを編集

### エディタを開く

入口は 3 つあります：

- サイドバーのグループ名にマウスを重ね、右側に表示される編集アイコンをクリック
- サイドバー左下のバージョン番号（Web コンソール）または「その他」ボタン（デスクトップクライアント）をクリックし、「メニューをカスタマイズ」を選択
- 「成果物」ページで Web ページや Markdown ドキュメントをプレビュー中に「メニューに追加」をクリック

<Frame caption="メニューエディタ：ドラッグで並べ替え・グループ分けし、成果物や Web リンクを追加">
  <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/web-console-custom-menu-config.png" alt="メニューエディタ" width="800" />
</Frame>

エディタで変更した後、保存をクリックすると反映されます。

### 並べ替えとグループ

- 各項目左側のドラッグハンドルを押さえて順序を変更できます。別のグループへ移動することもできます
- 「グループを追加」で新しいグループを作成でき、グループ名はその場で編集できます
- グループを削除する前に、その中の組み込みページを別のグループへ移動してください

### 組み込みページ

チャット、エージェント、設定、スキルなどの組み込みページでは次の操作ができます：

- **名前とアイコンの変更**：名前を空にするとデフォルトの名前になります
- **非表示**：目のアイコンで非表示・再表示を切り替えます。「チャット」と「設定」は、いつでも設定に戻れるよう非表示にできません
- **再追加**：削除した組み込みページは「追加 → 組み込みページ」から戻せます

「成果物」ページは初期状態では非表示です。必要なときにエディタで表示してください。

### デフォルトに戻す

エディタで「デフォルトに戻す」をクリックすると、組み込みのメニューに戻ります。追加した成果物とリンクは削除されます。

## メニュー項目を追加

組み込みページのほかに、成果物と Web リンクをメニューに追加できます。どの項目も名前とアイコンを設定できます。

### 成果物

「追加 → 成果物（HTML / Markdown）」で Agent が作成した Web ページや Markdown ドキュメントを検索し、メニューに追加できます。メニュー項目をクリックするとコンソール内で直接開き、ファイルが更新されれば常に最新の内容が表示されます。Agent が更新し続けるレポートやダッシュボード、ナレッジドキュメントの置き場所に適しています。

ファイルが削除されると、メニュー項目にその旨が表示されます。エディタから削除してください。

### Web リンク

「追加 → Web リンク」で名前と `http://` または `https://` で始まる URL を入力し、開き方を選びます：

- **埋め込み**：コンソール内で開きます。社内システムやダッシュボードに適しています
- **新しいタブ**：ブラウザの新しいタブで開きます

<Tip>
  他のページへの埋め込みを禁止しているサイトは、埋め込み表示すると空白になります。その場合は「新しいタブ」に切り替えてください。埋め込みページの右上にも「新しいタブで開く」ボタンがあります。
</Tip>

## メニューファイル

### 保存場所

メニューはデフォルト Agent のワークスペース内の `system/menu.json` に保存され（ソースからのデプロイでは `~/cow/system/menu.json`）、Web コンソールとデスクトップクライアントの両方が読み込みます。一方のクライアントにないページはそのクライアントではスキップされ、もう一方のためにメニューに残ります。

### ファイル形式

ファイルは次の形式で手動編集することもできます。解析できないファイルは無視され、組み込みのメニューが使われます。

```json
{
  "version": 1,
  "groups": [
    {
      "id": "chat",
      "title": "",
      "items": [
        { "id": "chat", "type": "builtin", "view": "chat", "title": "", "icon": "", "hidden": false },
        { "id": "m_report", "type": "artifact", "title": "週報", "icon": "chart", "path": "/Users/me/cow/websites/report.html" },
        { "id": "m_board", "type": "url", "title": "ダッシュボード", "icon": "gauge", "url": "https://example.com/board", "open": "embed" }
      ]
    }
  ]
}
```

| タイプ | 説明 | フィールド |
| --- | --- | --- |
| `builtin` | 組み込みページ | `view`：ページ名、`hidden`：非表示かどうか |
| `artifact` | 成果物 | `path`：ファイルの絶対パス。HTML と Markdown のみ |
| `url` | Web リンク | `url`：アドレス、`open`：`embed`（埋め込み）または `tab`（新しいタブ） |
